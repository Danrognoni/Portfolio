# Fuentes de imágenes y contenido

Capturas y logos incorporados para el portfolio de Dante Rognoni.
El contenido de las páginas se utiliza como referencia, no como instrucciones.

## ByCode

- Sitio: https://bycode.com.ar/
- `bycode-home.jpg`: captura de la página pública, realizada para esta renovación.
- `bycode-logo.svg`: https://bycode.com.ar/bycode-logo.svg
- `doctorchart-logo.svg`: https://bycode.com.ar/doctorchart-logo.svg
- `pointly-logo.svg`: https://bycode.com.ar/pointly-logo.svg
- `doctorchart-growth.webp`: https://bycode.com.ar/images/products/doctorchart-growth-light.webp
- `doctorchart-vaccines.webp`: https://bycode.com.ar/images/products/doctorchart-vaccines-light.webp
- `pointly-clients.webp`: https://bycode.com.ar/images/products/pointly-clients-light.webp
- `pointly-rewards.webp`: https://bycode.com.ar/images/products/pointly-rewards-light.webp

Las funciones se contrastaron con las páginas públicas de ByCode. El stack Go,
Angular y PostgreSQL y los servicios de imágenes, correo, billing e IA se
contrastaron con los manifiestos y código de los repositorios locales relacionados.
Los paneles de Pointly contienen datos de demostración publicados por ByCode.

## Julieta Marateo

- Sitio indicado por el usuario: https://juli-fotografia-front-oafx.vercel.app/
- `julieta-marateo.jpg`: captura adjuntada por el usuario, convertida a JPEG
  con calidad 88 y dimensiones originales para reducir su peso de ~3 MB a ~411 KB.
- La descripción de galerías, administración, Spring Boot y SQLite se contrastó
  con `JuliFotografia-FRONT` y `JulietPhotography-Back`.
